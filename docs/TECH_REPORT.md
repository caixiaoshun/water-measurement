# 技术报告（合同验收版）

## 1. 项目概述
本项目实现“动态水面自适应单目测距系统”最小可运行版本：
- 使用单目相机与水面共面约束进行两点测距；
- 支持基准点驱动的外参更新（PnP + RANSAC）；
- 支持水位补偿输入（静态/文件回放）；
- 提供 CLI demo 与自动化合同指标测试。

## 2. 数学模型与坐标约定
- 外参定义：`Xc = R * Xw + t`（世界到相机）。
- 水面平面：`n^T X + d = 0`，水平面写作 `z = h`。
- 测距流程：像素去畸变 -> 相机射线 -> 射线与水面求交 -> 两交点欧氏距离。

## 3. 关键模块
- `vision_ranging.py`
  - 相机参数管理、去畸变；
  - ArUco / Circle 基准点检测；
  - 检测器链式 fallback；
  - `solvePnPRansac` 外参估计与质量评分；
  - 测距与耗时统计。
- `water_level.py`
  - 静态值 / 文件回放读取；
  - 水位与平面融合。
- `main.py`
  - 配置读取、视频流输入、鼠标点选、结果输出。

## 4. 合同指标自动化验收
自动化文件：`tests/test_contract_metrics.py`。

对应关系：
1. 测距误差 <=5%：跨 2~50m 工况逐点断言。
2. 外参修正成功率 >=95%：Monte Carlo 扰动统计断言。
3. 修正后精度恢复 >=90%：`recovery` 公式断言，并附加后验误差<=5%。
4. 响应时间 <=1s：测距函数 P95 耗时断言 <=1000ms。
5. 标定通用性 >=3：三套相机模型均跑通去畸变+测距链路。
6. 基准点兼容性 >=2：Aruco 失效时 Circle fallback 仍可更新外参。
7. 交付物存在性：报告与核心源码文件存在且可导入。

## 5. Web 可视化演示
- 技术栈：FastAPI + 原生 HTML/JavaScript（`web/app.py` + `web/static/index.html`）
- 端点：`/health`（健康检查）、`/config`（配置摘要）、`/measure`（测距 API）、`/`（前端页面）
- 前端画布模拟 1280×720 相机视野，支持鼠标点选两点、显示测距结果与诊断信息（置信度、耗时、入射角、状态）
- 水位参数可实时调整
- 启动命令：`uvicorn web.app:app --host 0.0.0.0 --port 8765`

## 6. 执行方式
- 运行 demo：`python main.py --config config.yaml --input 0`
- 运行合同验收测试：`python -m pytest -q`

## 7. 扩展测试覆盖
`tests/test_complex_scenarios.py` 覆盖以下复杂因素：
- 像素抖动（±2px 随机噪声模拟人工点选）
- 水位跳变与缓慢漂移
- 姿态漂移 Monte Carlo（平移 >5cm, 倾斜 >2°）
- 基准点退化（ArUco 遮挡 → circle fallback）
- 退化几何（近平行射线、远处地平线）
- 透镜畸变与像素噪声
- 极值边界（2m / 50m / 亚米级）

## 8. 说明
测试使用可复现随机种子与可解释几何合成场景，不使用“固定返回通过”的伪逻辑。
